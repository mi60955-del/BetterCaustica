# dof_preview.py — 景深（薄透镜）离屏预览

把 `shaders/pipelines/world/primary.rgen.slang` 的相机镜头逐行移植到 numpy，在一张合成场景上出图：

- `math.slang` 的光圈采样：塑料数格点 + 逐像素相位，再按面积守恒映射到单位圆盘；
- `primary.rgen` 的主光线构造：把针孔光线在传感器平面内平移一个光圈点，再重新瞄准它穿过焦平面的位置；
- `RtDepthOfField.java` 的半径钳制：镜头半径就是拨盘本身（默认 4 cm）。上限分两档，各有一个开关：
  `dof.blur-cap` + `dof.max-blur`（默认 14 px）管总量，`dof.per-pixel-cap` 决定要不要把它落到每个像素上。
  远景那一档按 `半径 × |1 − 深度/焦距|` 的上界设限——地平线的弥散角 = 半径 / 焦距，是唯一由焦距说了算
  的那一档；逐像素那一档用该像素上一帧的深度，把贴脸的方块（0.6 格）从 47.6 px 压回 14 px。
  总量开关关掉就是物理正确的相机，也是马赛克。
- 焦距不是瞬移的：`dof.rack-time` 是那条指数滑行的时间常数（默认 0.2 s），预览按同一公式核对。

`dof.pinhole-guides`（引导缓冲留在针孔光线上的那一趟探针）在预览里没有对应物：它管的是 DLSS-RR 拿到
什么的引导，而预览既没有重建器也没有历史帧。

场景是一块透视地面加三块不同深度的点阵测试板，六格对照：针孔、默认 4 cm 镜头、三倍口径（12 cm）、
上限关闭、逐像素上限关闭（只兜地平线），以及"只有一帧"（每像素一个光圈点）——最后一格就是进游戏后
DLSS-RR 需要几十帧才收敛掉的那张噪声图。

用途：改光圈采样、焦距语义或口径钳制时几秒出对照图，不必每次进游戏等世界加载。
**这不是像素级复刻**——它复刻的是几何：没有纹理、雾、反射，也没有降噪器。镜头唯一改变的就是
每个采样落在哪里，而这件事它算得和游戏里一样。

## 运行

```bash
python tools/dof_preview.py --width 640 --height 360
# 输出到 tools/dof-preview-out/dof-sheet.png
```

`--display-height` 是上限所按的那一帧高度，对应 `RtComposite` 传给镜头的 `displayH`；上限按最终画面计，
面板按自己的高度画，所以打印的远景像素值以游戏分辨率为准。`--aperture`（厘米）、`--focus`、`--fov-y`、
`--samples` 对应设置项与采样帧数，`--cap` 对应 **Max Blur Radius** 滑块（`--cap 0` 等于关掉 **Cap Blur
Radius** 开关），`--no-pixel-cap` 等于关掉 **Cap Each Pixel** 开关。

每次运行打印一张表：每块测试板的弥散圆（厘米）、弥散圆（像素）、被上限压过之后的弥散圆（像素）、
以及针孔与镜头渲染在同一块板上的亮度对比度。默认参数（4 cm 镜头、焦点 8 格、1080p、上限 14 px、
32 个光圈采样）：

```
chart depth   disc (cm)   disc (px)   bounded (px)   contrast pinhole -> lens
     0.6          3.7        47.6          14.0         0.219 ->  0.095
     8.0          0.0         0.0           0.0         0.217 ->  0.217
    40.0         16.0         3.1           3.1         0.199 ->  0.177
```

贴脸那块从 47.6 px 收进 14.0 px——这就是"逐像素上限"存在的全部理由；焦平面那块一点不变；远处那块
本来就在上限之下，所以 `bounded` 和 `disc` 相同。地平线（深度 → ∞）落在 3.9 px = 半径 / 焦距，
是 `disc` 列唯一的渐近值，由 `RtDepthOfField.push` 的 `Math.min` 那一档兜住。

## 约定

- `LENS_LATTICE_STEPS`、格点掩码、像素种子混合常数必须与 `math.slang` / `primary.rgen` 里的声明一致，
  `FAR_BLOCKS`、`NEAR_BLOCK` 与 `CausticaConfig` 的默认值（`dof.rack-time`、`dof.max-blur`、`dof.aperture`、
  `dof.focus-distance`，以及三个默认打开的开关）也一样。
  `tools/test_dof_preview.py` 会解析两边的声明逐条比对，改动后跑：

  ```bash
  python -m unittest tools.test_dof_preview
  ```

  同一份测试还检查几何本身：焦平面必须落在针孔光线与该平面交点的**同一个点**上（差 < 1e-9 格），
  弥散圆必须等于解析值，远景在任意焦距、任意分辨率、任意 FOV 下都不许越过上限且不得大于拨盘本身，
  逐像素上限必须等于 `上限 × s × f / (f − s)`、在任意深度上都不越过拨盘，关掉开关时逐档都退回拨盘，
  滑块拉开时虚化单调变强；逐像素开关关掉后每一档都退回地平线那一档；读回的上一帧深度必须先夹进
  `[0, 焦距]` 才能进光线（没写过的格子因此是针孔，而不是显存里的那个随机数），
  探针必须受 `dof.w` 管、深度写入必须受 `dof.z` 管，
  像素到正切跨度的换算必须走 `2/|m11|` 而不是 `atan`（这条是实战换来的：混用会差 15%~49%），
  零半径必须逐位复现针孔光线。
- 自动对焦读的是**追踪出来的深度**（`shaders/pipelines/dof_focus`），不是 CPU 打出去的那条方块射线。
  统计量是窗口内距离的调和平均——也就是屈光度 `1/距离` 的均值再取倒数，因为镜头的弥散本来就按 `1/s` 算：
  半格外一块、五十格外九块，算术平均给 45 格（近处那块被完全推到焦外），屈光平均给 4.59 格。
  天空被夹到 `FAR_BLOCKS`，所以满屏天空就是对焦在无穷；没写过的格子（`<= 0`、NaN、荒谬值）不计入。
  `meter_focus()` 是这套规则的 numpy 版，`FocusMeter` 那组用例逐条核对。
- 反射对焦（`dof.reflection-focus`）不新增一条规则，只换那个距离：平面反射体把被反射的东西成像在自己
  身后同样远处，所以镜像的**轴向距离 = 界面自己的 × (1 + 镜面到物的距离 / 眼到镜面的距离)**，正落在眼睛
  看下去的那条直线上——镜头本来就按那条线摆焦平面。只有镜像波瓣占了这个像素相当份额时才算数
  （`REFLECT_IMAGE_SHARE`），水面大约在 8 格外越过这条线，脚边的水不算。`MirrorFocus` 那组用例用
  光圈光线打镜面再求交来核对：焦在镜像上光线汇聚到物点上（残差 0.00 mm），焦在镜面上则偏 134 mm，
  1080p 下是 7.45 px 的弥散圆。
- 所有深度——焦距和测试板的深度——都从**镜头平面**量起，也就是从近裁剪面量起。游戏里的镜头也放在
  近裁剪面上：视图摇晃被烘进投影矩阵，针孔位置因此不是这些反投影能命名的点，而近裁剪面是。
- 光圈点必须逐像素错开相位：整屏共用一个采样点会平移画面而不是虚化它。测试用相邻像素的差分来卡这一条。
- 测试板的点周期随深度等比放大，好让每块板在画面上占据同样的空间频率；否则远处那块本来就是亚像素的，
  虚不虚化都读不出对比度。

## 进游戏核对

`docs/developer_guide.md` 的 "Per-pass GPU timing" 一节：`-Dcaustica.rt.gpuTiming=true`
会把每段 GPU 时间写进 `rt-frame-stats/gpu.csv`。镜头不新增任何 dispatch，辐射那条主光线也只有一条；
代价是引导探针：开着镜头时 Pass A 会把 0 次反弹那段在针孔方向上再走一遍，因为 DLSS-RR 的分类与重投影
只认针孔相机。探针 `guidesOnly=true`，跳过雾、光柱、水的积分与分裂，所以它比辐射那一趟便宜得多，
而且 **Pinhole Guides** 开关（`dof.w`）一关就整个没有。关掉 `dof.enabled` 时镜头与探针一起消失，
`tracePrimaryMs` 应回到原值；`dof.per-pixel-cap` 关掉则省掉那张渲染分辨率 r32f 深度图的读写。

预览验不了的两件事都已经进游戏验过了，结论都写进了 shader 注释：引导缓冲跟着光圈点走会被 RR 抹成
一层逐帧闪烁的糊（所以有了探针），无上限的近景弥散圆会被降噪器交回马赛克而不是虚化（所以有了滑块）。
剩下的只有数值：把 **Max Blur Radius** 拉到 2 px，画面会退化成近似针孔；拉到 48 px，贴脸方块开始碎；
**Focus Time** 拉到 1 s，转身对着一面墙时焦平面会明显慢半拍地滑过去。
